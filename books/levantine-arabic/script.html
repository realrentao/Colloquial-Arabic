教材 02 · 专题

阿拉伯文字书写补充

元音符号、长元音与双元音、连写规则、太阳字母，以及 ق 与 ة 的黎凡特读法。

书写规则与本站改写说明

依据原书 Transliteration key · Table 2–5 与 Introduction

元音符号与本站的加注方式

普通阿拉伯文文本只写长元音字母，短元音靠上下文推断。本站按教材读音给每个实词补上 فَتْحَة、كَسْرَة、ضَمَّة、سُكُون 与 شَدَّة，学习者可以直接看着字形读出黎凡特口语。

长元音与双元音

اَلِف 承载 ā，وَاو 承载 ū／ō，يَاء 承载 ī／ē；双元音 aw 写 ـَوْ、ay 写 ـَيْ。原书 Table 2、Table 4 把长音与双音并列，正是因为它们共用同一组字母。

تَنْوِين 与词尾语法

ً ٌ ٍ 是短元音加鼻音 -n 的词尾形式，多出现在书面语与固定问候（如 أَهْلًا وَسَهْلًا、شُكْرًا）。黎凡特口语里通常不读出这个 -n，本站保留书写但按口语加元音。

شَدَّة 与字母连写

شَدَّة 叠音会改变词义，必须写清；阿拉伯字母连写时每个字母有词首、词中、词尾、独立四种字形，其中 ا د ذ ر ز و ة 只连前不连后。原书 Table 1 逐字母给出全部字形。

冠词与太阳字母

定冠词 اَلْ 遇到 ت ث د ذ ر ز س ش ص ض ط ظ ل ن 这类太阳字母时，ل 不发音、后接字母带 شَدَّة，如 اَلشَّمْسُ、اَلنُّورُ。黎凡特口语中冠词元音还会随词首辅音变化。

ق 的黎凡特读法

ق 在标准语读小舌塞音 q；黎凡特城市口语多读喉塞音 ء，贝都因与部分乡村口音读 g。原书 Table 1 注明这一差异。本站一律写 ق，读音按城市口语处理。

ة 与 ى

ة（تَاء مَرْبُوطَة）在黎凡特多读 -ih／-e，只有连读时才读 -t；ى（أَلِف مَقْصُورَة）读短 a。二者都是词尾专用字形，不能与 ت、ي ا 混写。

هَمْزَة 的写法

ء 可独立书写，也可坐在 ا و ي 上写成 أ إ آ ؤ ئ。黎凡特口语常把词中的 hamza 变成长元音，如 رَأْيُك 读 raayak；本站按实际口语读音加元音，字形仍按教材词汇表保留。
