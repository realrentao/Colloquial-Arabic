第 10 单元 · 初级

关系从句与指示词

الْجُمْلَةُ النَّسَبِيَّةُ وَأَسْمَاءُ الْإِشَارَةِ
关系从句、指示代词与指示形容词、等式句的否定、“有人”与“没有人”
原书标题转写：al-júmla n-nasabíyya wa asmáa' al-isháara
学习目标情景对话词汇表语法要点练习文化点滴本单元小结

01 学习目标

  • 掌握关系代词 الّذِي 在定指与不定指先行词后的不同用法
  • 区分指示代词与指示形容词的阴阳性、远近指及前后位置
  • 学会用 مُبْ / مُو 否定没有动词的等式句
  • 掌握 أَحَد 与 مَحَّد 表达“有人”和“没有人”

02 情景对话

抱怨医生开的药　الشَّكْوَى مِنَ الدَّوَاءِ

甲遇见老朋友贾西姆，关切地询问他的身体状况；贾西姆抱怨医生开的药既没用又难吃，甲最后拿冰箱里冰镇百事的玩笑安慰他。

甲
يَا هَلَا جَاسِم! شَلُونِكَ؟
嗨，贾西姆！你好吗？
原书罗马音：yaa hála jáasim! shlóonik?
乙
أَهْلًا أَهْلًا أَبُو خَلِيلٍ. وَاللّٰهَ، أَنَا مُبْ زَيْنًا الْيَوْمَ.
你好你好，阿布·哈利勒。老实说，我今天不太舒服。
原书罗马音：áhlan áhlan abu xalíil. wállah, ana mub zayn il-yoom.
甲
لَيْش؟ شْفِيكَ، تَعْبَانٌ؟
怎么了？你怎么啦，是累了吗？
原书罗马音：laysh? shfíik, ta9báan?
乙
أَيْ، عِنْدِي زُكَامٌ شُوَيٌّ … رَأْسِي دَايِرٌ.
是啊，我有点儿感冒……头晕乎乎的。
原书罗马音：ay, 9índi zukáam shway … ráasi dáayir.
甲
مَا رِحْتَ الدَّكْتَرَ؟
你没去看医生吗？
原书罗马音：maa riHt id-dáxtar?
乙
بَلَى رِحْتُ، بَسْ مَا أَعْطَانِي دَوَاءً زَيْنًا. وَاللّٰهَ، الدَّكَاكِتْرُ ذَيْلَاكْ مَا فِيهِمْ فَائِدَةٌ …

原书罗马音：bála riHt, bas maa 9aTáani dáwa zayn. wállah, id-daxáatir dhayláak maa fíihum fáyda …
甲
شْقَالَ لَكَ الدَّكْتَرُ عَيَّالَ؟

原书罗马音：sh-gaal lik id-dáxtar 9áyal?
乙
خَرَابِيطُ يَعْنِي. قَالَ لِيِّي بَسْ: «خُذْ هَدَّوَاءَ مَرَّتَيْنِ كُلَّ يَوْمٍ وَخُذْ رَاحَتَكَ فِي الْبَيْتِ».

原书罗马音：xaraabíiT yá9ni. gaal líyyi bas 'xudh had-dáwa marratáyn kill yoom u xudh ráaHtik fil-bayt'

وَالدَّوَاءُ الّذِي أَعْطَاكَ إِيَّاهُ، شِينْهُو يَعْنِي؟

原书罗马音：u had-dáwa ílli 9aTáak iyyáah, shínhu ya9ni?
乙

原书罗马音：Hbúub báyDa Saghíira bas. layn ríja9t il-bayt akált wáHda mínha láakin idh-dhoog máalha muu zayn – karíih, ya9ni. maa akált mínha bá9ad – gaTTáyt il-báagi.
甲
أَنَا عِنْدِي فِكْرَةٌ زَيْنَةٌ!
我有个好主意！
原书罗马音：ana 9índi fíkra záyna!
乙
قُلْ!
说吧！
原书罗马音：guul!
甲
هَسْتُ دَوَاءٌ أَحْسَنُ مِنْ هَدَّوَاءِ الّذِي أَعْطَاكَ إِيَّاهُ … وَهَدَّوَاءٌ مَوْجُودٌ فِي الثَّلَّاجَةِ مَالَتِي!
有一种药比他给你的那个好……而且就在我冰箱里！
原书罗马音：hast dáwa áHsan min had-dáwa ílli 9aTáak iyyáah … u had-dáwa mawjúud fith-thalláaja máalti!
乙
شِينْهُو، يَعْنِي؟
是什么呀？
原书罗马音：shínhu, ya9ni?
甲
غَرْشَةُ بَابْسِي كِلِّشْ بَارِدَةٌ!
一瓶冰镇百事可乐！
原书罗马音：ghárshat bábsi kíllish báarid!

04 语法要点

关系从句：关系代词 الّذِي 的用法

在“我看见了那个摔断腿的男人”这类句子里，الّذِي（ílli，“……的”）回指前面的先行词，并在从句中充当成分。先行词若是定指的——带定冠词 ال 或带人称代词后缀——就必须用 الّذِي；若是不定指的，则不加 الّذِي。它既可作从句动词的主语，也可作宾语；作宾语时，先行词还要在从句动词之后用一个性数一致的代词“回指”一次，这一点不论定指与否都成立。此外，الّذِي 还能在主句里泛指“……的人/事”，相当于“that which / he who”。
شِفْتُ الرَّجُلَ الّذِي كَسَرَ رِجْلَهُ.
我看见了那个摔断腿的男人。（定指，用 الّذِي）
原书罗马音：shift ir-rayyáal ílli kísar ríilah.
شِفْتُ رَجُلًا كَسَرَ رِجْلَهُ.
我看见一个摔断腿的男人。（不定指，不用 الّذِي）
原书罗马音：shift rayyáal kísar ríilah.
الرَّجُلُ الّذِي شِفْتُهُ فِي الشَّارِعِ …
我在街上看见的那个男人……（作宾语，动词后回指 -hu）
原书罗马音：ir-rayyáal ílli shíftah fish-sháari9 ...
الصَّحِيفَةُ الّتِي أَعْطَيْتُكَ إِيَّاهَا …
我给你的那份报纸……（阴性先行词用 الّتِي，回指 -ha）
原书罗马音：il-jaríida ílli 9aTáytik iyyáaha ...
إِلِّي رَاحَ رَاحَ.
过去的就过去了。（الّذِي 在主句中泛指“……的”）
原书罗马音：ílli raaH raaH.
判断口诀：“定指用 الّذِي，不定指不用；作宾语别忘动词后的代词回指。”

指示代词：这个、那个、这些、那些

指示代词按阴阳性区分：هَاذَا（这个，阳）对 هَاذِي（这个，阴）；هَاذَاكَ（那个，阳）对 هَاذِيش（那个，阴）。复数有 هَاذَيْلَيْن（这些）、هَاذَيْلَاكْ 与 هَاذُولَاكْ（那些）。“这个/这些”指时空上离说话人较近的人或物，“那个/那些”指较远的。海湾口语里指示代词常放在所修饰名词之后，此时除 هَاذَا 外通常省去词首的 هَا- 成分，意义不变。在“这是某某人”这类等式句中，指示词与名词之间必须插入独立人称代词 هُوَّه / هِيَّه / هُمَّه。
هَاذَا زَيْنٌ.
这个很好。
原书罗马音：háadha zayn.
هَاذِي فِكْرَةٌ زَيْنَةٌ.
这是个好主意。
原书罗马音：háadhi fíkra záyna.
هَاذِيشْ بِنْتٌ شَاطِرَةٌ.
那是个聪明的女孩。
原书罗马音：haadhíich bint sháaTra.
هَاذَيْلَاكْ كَسْلَانِينَ.
那些人很懒。
原书罗马音：haadhayláak kaslaaníin.
زَيْنٌ، هَاذَا.
这个很好（指示代词后置）。
原书罗马音：zayn, háadha.
هَاذِي هِيَّهْ لْبِنْتُ الّتِي نَجَحَتْ فِي الِامْتِحَانِ.
这就是那个通过考试的女孩。（等式句插入 هِيَّه）
原书罗马音：háadhi híyya l-bint ílli níjHat fil-imtiHáan.
阴性形式以 -i / -ich 结尾，阳性以 -a / -ak 结尾；“这是那位……”中间别忘了加 هُوَّه / هِيَّه / هُمَّه。

指示形容词：这个人、那座房子

要说“这个人、那个女孩、那些房子”，把指示词加在定指名词之前，相当于“这＋那个男人”。“这个/这些”用缩略的 هَرْ- / هَلْ- 等前缀接定指名词，“那个/那些”用 ذَاكَ / ذِيشْ / ذَيلَاكْ 等接定指名词，括号中的 هَا 成分都可省略。指示词也可放在整个名词短语之后，此时 هَاذَا 绝不缩略，其余则常省去 هَا。关键是：名词必须带定冠词 ال；一旦省略 ال，指示词就变成上一条的指示代词，意思从“这个人是好人”变成“这是个好人”。若名词短语较长（如“这位公司经理”），指示词须紧跟完整短语，并与中心词（مُدِير）而非后置名词保持性数一致。
هَاذَا الرَّجُلُ زَيْنٌ. / هَرَّجُلُ زَيْنٌ.
这个人是好人。
原书罗马音：háadha r-rayyáal zayn. / har-rayyáal zayn.
هَاذِي الْأَسْعَارُ غَالِيَةٌ. / هَلْأَسْعَارُ غَالِيَةٌ.
这些价格很高。
原书罗马音：háadhi l-as9áar gháalya. / hal-as9áar gháalya.
هَاذِيشْ اللَّيْلَةُ رِحْنَا السِّينَمَا.
那天晚上我们去了电影院。
原书罗马音：haadhíich il-láyla ríHna s-síinama.
الرَّجُلُ هَاذَا زَيْنٌ.
这个人是好人（指示词后置）。
原书罗马音：ir-rayyáal háadha zayn.
مُدِيرُ الشَّرِكَةِ هَاذَا.
这位公司经理（与中心词 مُدِير 阳性一致）。
原书罗马音：mudíir ish-shárika háadha.
有没有 ال 决定它是“指示形容词”还是“指示代词”；后置时必须放在完整名词短语之后，并与中心词保持一致。

等式句的否定：مُبْ / مُو

مَا 用来否定动词以及 عِنْدَهُ、فِيهِ 这类“准动词”，例如“我没生你的气”“我什么都没有”。但在没有动词、也没有准动词的“等式句”（即“A 是 B”结构）里，否定词要用 مُبْ 或 مُو，相当于汉语的“不是”。例如“这不好”“这儿的饭不便宜”“艾哈迈德不在这儿”。
هَاذَا مُبْ زَيْنٌ.
这不好。
原书罗马音：háadha mub zayn.
الْأَكْلُ هُنَا مُبْ رَخِيصٌ.
这儿的饭不便宜。
原书罗马音：il-ákil ihni mub raxíiS.
أَنَا مُبْ زَعْلَانٌ عَلَيْكَ.
我没生你的气。
原书罗马音：ana mub za9láan 9aláyk.
أَحْمَدُ مُو مَوْجُودٌ.
艾哈迈德不在这儿。
原书罗马音：áHmad muu mawjúud.
مَا عِنْدِي شَيْءٌ.
我什么都没有。（准动词的否定仍用 مَا）
原书罗马音：maa 9índi shay.
有动词或准动词 → 用 مَا；纯粹“是/不是”的等式句 → 用 مُبْ / مُو。

“有人”与“没有人”：أَحَد 与 مَحَّد

“有人、某人”是 أَحَدٌ，“没有人”是 مَحَّدٌ。表达“没有人……”有两种等价说法：直接用 مَحَّدٌ 作主语，或用 مَا + 动词 + أَحَدٌ。例如“屋里没有人”“我在街上没遇见任何人”。要注意 مَحَّد 本身已带否定意义，不能再加 مَا；若用了 مَا，后面就必须跟 أَحَدٌ。
كَانَ مَحَّدٌ فِي الْبَيْتِ.
屋里没有人。
原书罗马音：kaan máHHad fil-bayt.
مَا كَانَ أَحَدٌ فِي الْبَيْتِ.
屋里没有人。（另一说法）
原书罗马音：maa kaan áHad fil-bayt.
لَقِيتُ مَحَّدًا فِي الشَّارِعِ.
我在街上没遇见任何人。
原书罗马音：ligáyt máHHad fish-sháari9.
مَا لَقِيتُ أَحَدًا فِي الشَّارِعِ.
我在街上没遇见任何人。（另一说法）
原书罗马音：maa ligáyt áHad fish-sháari9.
فِيهِ أَحَدٌ بَرَّةً.
外面有人。
原书罗马音：fii áHad bárra.
مَحَّد = 没有人，单独用；مَا … أَحَد = 没有任何人，两式不要混用。

06 文化点滴

海湾女性的传统服饰与海湾人的姓名名片

服饰是自我形象的表达，二十一世纪初的海湾社会尤其如此：与二十年前相比，女性着装带上更浓厚的宗教色彩。老一辈女性日常仍穿宽松的浅色棉布长裤 سِرْوَال，裤脚窄而有刺绣，外面罩一件长及膝下、上衣与裙子相连的 دَرَّاعَة。乡村常用印花棉布，喜庆场合则穿更修身、深色（有时全黑）的款式，领口和窄袖缀满金线刺绣。未到青春期的女孩只穿 سِرْوَال 与简单的 دَرَّاعَة，再戴露出面部的头巾 بُخْنُغ。成年女性在 دَرَّاعَة 外面还会套一件称作 ثَوْب 的长袍，式样因面料和装饰而异，例如巴林婚礼上穿的鲜艳丝绸 ثُوب النِّشَل。出门时，女性普遍罩一件素黑丝绸斗篷 عَبَا / عَبَايَة 或 دَفَّة，常配面纱：黑线绣花的 مِلْفَع，或在海湾多地常见的带眼孔面罩 بُرْقُع / بَطُّولَة；巴林乡村女性则改穿轻薄的彩色棉斗篷 مِشْمَر。所有这些遮盖统称为 حِجَاب，体现伊斯兰的 حِشْمَة（端庄）观念，近年在许多阿拉伯国家又流行起长袍配紧裹头巾的样式，穿者被称为 مُحَجَّبَات。海湾人名一般是“本名—父名—祖父名”，男女皆然；阿曼和沙特常在二三名之间加 bin（儿子），女性则在名与父名之间加 bint（女儿），且婚后不改姓。部落或家族名置于末尾，王室不用普通冠词 al-，而用意为“家族、王室”的 āl。人名最常见于店招与名片，名片上还常出现 دكتور（博士/医生）、ص.ب（邮政信箱）等缩略语，以及 jawwáal 或 mutaHárrik（手机）等词。

读海湾名片时，先找姓名与职业，再认 دكتور、ص.ب 等缩略语；人名中的 bin / bint 表示“某某之子 / 女”，王室的 āl 是“家族”而非普通定冠词 al-，两者切不可混淆。

✓ 本单元小结

本单元围绕关系从句展开：你学会了在定指先行词后用 الّذِي / الّتِي 连接从句，也明白了不定指时不加关系代词、作宾语时须用代词回指的规则。接着你掌握了指示代词与指示形容词的阴阳性、远近指区别，以及它们与定指名词搭配时的前后位置。你还学会了用 مُبْ / مُو 否定无动词的等式句，用 أَحَد 与 مَحَّد 表达“有人”和“没有人”。最后的对话里，你听到海湾人如何用 شَلُونِكَ 问候、抱怨医生开的药，并以一句冰镇百事的玩笑收尾。
