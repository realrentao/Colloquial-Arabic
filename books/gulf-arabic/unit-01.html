第 1 单元 · 入门

你好，欢迎！

أَهْلًا وَسَهْلًا
数量表达、命令与请求、礼貌用语
原书标题转写：áhlan wa sáhlan
学习目标词汇表语法要点练习文化点滴本单元小结

01 学习目标

  • 学会用杯、瓶、打、半、四分之一等词构成数量短语
  • 掌握命令式对男性、对女性、对众人三种形式
  • 会用「请」「谢谢」「请便」等礼貌用语并招呼对方
  • 认识海湾国家与海合会及相关地名

04 语法要点

数量短语：容器、单位与量词

海湾口语把「玻璃杯、咖啡杯、瓶子、一打、半、四分之一」等词直接放在名词前构成数量短语，中间不需要「一个」和「的」。以 -a 结尾的阴性词（原书词汇表标 *）进入短语时会显出被「藏起来」的词尾 -t，如 gúT9a → gúT9at láHam。此外，bayD（蛋）、símich（鱼）、xúbuz（面包）是集合名词，泛指一类东西；若说「一个」，须加阴性词尾 -a 构成个体名词：báyDa、símicha、xúbza。
جِلَاسْ چَاي
一杯茶
原书罗马音：glaas chaay
فِنْجَالْ قَهْوَة
一杯咖啡
原书罗马音：finjáal gáhwa
بُوطِلْ حَلِيب
一瓶牛奶
原书罗马音：búTil Halíib
نُصّ كَايْلُو لَحْم
半公斤肉
原书罗马音：nuSS káylo láHam
قُطْعَتْ لَحْم
一块肉
原书罗马音：gúT9at láHam
بَيْضَة
一个鸡蛋
原书罗马音：báyDa
短语里第一个词若以 -a 结尾，记得补出 -t：níTfa → nítfat xúbuz（一点儿面包），Hábba → Hábbat 9aysh（一粒米）。

命令式：对男性、对女性、对众人

用一个词即可表示命令。对男性单数用基本形式；对女性单数加词尾 -i；对多人加词尾 -u。原书把三种形式并列，本单元按硬规则拆成独立词条，便于分别检索和点读。
أَعْطِ / أَعْطِي / أَعْطُوا
给！／给！（对女性）／给！（对众人）
原书罗马音：9aT / 9áTi / 9áTu
جِيب / جِيبِي / جِيبُوا
带来！／带来！（对女性）／带来！（对众人）
原书罗马音：jiib / jíibi / jíibu
سَوِّ / سَوِّي / سَوُّوا
做！／做！（对女性）／做！（对众人）
原书罗马音：saww / sáwwi / sáwwu
رُحْ / رُوحِي / رُوحُوا
去！／去！（对女性）／去！（对众人）
原书罗马音：ruuH / rúuHi / rúuHu
تَعَالَ / تَعَالِي / تَعَالُوا
过来！／过来！（对女性）／过来！（对众人）
原书罗马音：ta9áal / ta9áali / ta9áalu
在命令前加 يَلَّا（yállah）可加强催促语气：يَلَّا، رُحْ!（快点走吧！）

「给我」与「为我」：-ni 与 lii

说「给我！」，把 -ni（我）直接接在命令式后：9aT → 9áTni；阴性 -i 与复数 -u 接 -ni 时元音拉长并带重音，成为 9aTíini、9aTúuni。说「带来给我」「做给我」则不用 -ni，而用 lii（或 líyyi，意为「为我、给我」）接在命令式之后。
أَعْطِنِي
给我！（对男性）
原书罗马音：9áTni
أَعْطِينِي
给我！（对女性）
原书罗马音：9aTíini
أَعْطُونِي
给我！（对众人）
原书罗马音：9aTúuni
جِيبْ لِي نُصّ كَايْلُو سِمِيچ
给我带来半公斤鱼
原书罗马音：jiib lii nuSS káylo símich
سَوِّ لِي فِنْجَالْ قَهْوَة
给我做一杯咖啡（对男性）
原书罗马音：saww lii finjáal gáhwa
记住分工：أَعْطِ 类用 -ni，جِيب／سَوِّ 类用 lii；口语中 lii 也说成 líyyi。

礼貌用语：请、谢谢、请便与称呼

命令式加上「请」字即更客气：对男性说 min fáDlik（或 fáDlak），对女性说 min fáDlich（或 fáDlach），对众人说 min fáDlakum。招呼人时用 yaa 加姓名，不知姓名就喊 naas（大家）。道谢除 shúkran 外，海湾口语还常说 aHsánt（对男性）、aHsánti（对女性）、aHsántu（对众人），字面是「你做得好」。递东西或请人先用时说「请便」：tafáDDal（对男性）、tafáDDali（对女性）、tafáDDalu（对众人）。
يَا عَلِيّ، جِيبْ لِي نُصّ كَايْلُو سِمِيچ مِنْ فَضْلِكَ
阿里，请给我带来半公斤鱼。
原书罗马音：yaa 9áli, jiib lii nuSS káylo símich min fáDlak
يَا زَهْرَة، أَعْطِينِي نِطْفَتْ خُبُز مِنْ فَضْلِچِ
宰赫拉，请给我一点儿面包。
原书罗马音：yaa záhra, 9aTíini nítfat xúbuz min fáDlich
يَا نَاس، تَعَالُوا مِنْ فَضْلِكُمْ!
请大家过来！
原书罗马音：yaa naas, ta9áalu min fáDlakum!
شُكْرًا / أَحْسَنْتَ / أَحْسَنْتِ / أَحْسَنْتُو
谢谢／多谢（对男性）／多谢（对女性）／多谢（对众人）
原书罗马音：shúkran / aHsánt / aHsánti / aHsántu
تَفَضَّلُوا چَاي!
请各位喝茶！
原书罗马音：tafáDDalu chaay!
注意性别一致：对女性说话时，命令式加 -i、请说 fáDlich、道谢说 aHsánti，三者要配套。

06 文化点滴

海湾国家与海合会

除阿曼早在1650年赶走葡萄牙人即获独立外，海湾各国取得政治独立的时间都不算长：科威特于1961年独立，巴林、卡塔尔和阿联酋则在20世纪70年代陆续结束与英国的条约关系后独立。海湾国家在阿拉伯语中称作 dúwal al-xalíij（海湾诸国），口语里分别叫科威特 il-kwáyt、巴林 il-baHráyn、卡塔尔 gáTar、阿联酋 il-imaaráat；阿曼除 9umáan 外，本国人还常称它为 is-sálTana（苏丹国）。沙特阿拉伯王国1932年成立，口语多称 is-sa9úudiyya，沙特人自己也常简称为 il-mámlaka（王国）；不过巴林自2002年起也成了王国，这一叫法如今便可能产生歧义。与人们印象不同，海湾国家并非都盛产石油：巴林虽在20世纪30年代最早打出石油，但储量一直有限，如今出口收入中相当一部分来自为邻国加工原油的炼油业和制铝业；2005年，作为阿联酋七个酋长国之一的迪拜，油气收入只约占其国内生产总值的百分之六，主要创收靠贸易、转口和金融服务。尽管各有差异，各国却有许多共性：从北部科威特到南部阿联酋的方言差别不大（阿曼差异较明显），都有在20世纪30年代前依赖采珠、此后转向石油的相似经济史，都与印度、东非和远东有着悠久的海上贸易往来，也共享一套社会文化价值观。1981年，海湾国家联合成立海湾合作委员会（GCC），阿拉伯语称 májlis at-ta9áawun al-xalíiji，本质上是一个贸易集团，旨在加强成员国在金融、贸易、旅游和科研方面的合作，并对共同关心的问题采取「海湾共同立场」。也门目前尚非海合会成员，但已提交加入申请。

许多海湾地名带定冠词 ال，如 il-kwáyt（科威特）、il-baHráyn（巴林）；也有不带的，如 dùbayy（迪拜）、gáTar（卡塔尔）。地名往往有含义：马斯喀特（Muscat）与其姊妹城穆特拉（Mutrah）都意为「锚地」；al-BaHrayn 意为「两海」，传统上指环绕巴林群岛的咸水与昔日丰沛的地下淡水；al-Kuwayt 意为「小堡垒」，ar-RiyaaD 意为「花园、草地」，ad-DooHa 在海湾口语中是「海湾」的说法之一；Abu Dhabi 直译「瞪羚之父」——海湾口语常用「某之父／某之母」表示某地盛产某物，如麦纳麦（意为「歇脚处」）的 Umm il-Hasam 意为「卵石之母」，科威特的 Umm il-Namal 则意为「蚂蚁之母」。

✓ 本单元小结

本单元学会了用 جِلَاسْ、فِنْجَال、بُوطِل、دَرْزَن、نُصّ、رُبْع 等词构成数量短语，并懂得以 -a 结尾的阴性词在短语中会显出隐性词尾 -t，集合名词加 -a 可变为个体名词。命令式按对象分为对男性、对女性加 -i、对众人加 -u 三式；「给我」加 -ni，「带来／做给我」用 lii，句首还可加 يَلَّا 加强语气。礼貌表达包括min fáDlik／چِ／kum（请）、shúkran 与 aHsant/i/u（谢谢）、tafáDDal/i/u（请便），以及用 yaa 加人名或 naas 招呼对方。最后认识了海湾国家的独立史、石油与经济、海合会，以及一批带或不带定冠词的地名及其含义。
