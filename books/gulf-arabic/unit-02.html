第二单元：定冠词、双数与复数

الْوَحْدَةُ الثَّانِيَةُ
定冠词 il 与太阳字母同化、双数 -ayn、后缀式与破碎式复数
原书标题转写：il-wáHda th-tháaniya
学习目标词汇表语法要点练习文化点滴本单元小结

01 学习目标

  • 掌握定冠词 il 的用法及与太阳字母的同化
  • 学会用后缀 -ayn 构成双数
  • 理解后缀式复数（-iin、-aat、-iyya）
  • 认识破碎式复数的基本元音模式

04 语法要点

定冠词 il 与太阳字母同化

海湾阿拉伯语里相当于英语 the 的定冠词是 il，和英语一样放在名词之前。当 il 后面的名词以“太阳字母”（t、th、d、dh、z、r、s、sh、S、D、T、DH、n、l）开头时，il 的 l 会同化，也就是变成与后一个字母相同的音，读成双辅音；这个 doubled 音要拖得比英语习惯长得多。名词以“月亮字母”（b、p、ch、j、x、H、k、f、g、gh、9、q、m、h、w、y）开头时则不同化。于是 is-sayyáara（那辆车）、iT-Tayyáara（那架飞机）、ir-riyáD（利雅得）都要同化，而 il-baab（那扇门）、il-jaríida（那份报纸）、il-kwáyt（科威特）保持 il 不变。
جِلَاس ←→ الْجِلَاس
一个玻璃杯 → 那个玻璃杯（非太阳字母，不变）
原书罗马音：glaas → il-glaas
سُوق ←→ السُّوق
市场 → 那个市场（س 同化，读双辅音）
原书罗马音：suug → is-suug
رَيَّال ←→ الرَّيَّال
男人 → 那个男人（ر 同化）
原书罗马音：rayyáal → ir-rayyáal
بَاب ←→ الْبَاب
门 → 那扇门（ب 不 同化）
原书罗马音：baab → il-baab
判断同化只看名词首字母，不看冠词本身；遇到 s、sh、S、T、D、n 等开头词，读时务必把第一个辅音拉长一倍。

双数：后缀 -ayn

想表达“两个……”而不是三个或以上时，阿拉伯语用专门的“双数”形式：在名词后加后缀 -ayn，重音落在 -ayn 上（因为它是词里最后一个长音节）。例如 rayyáal（一个男人）变 rayyaaláyn（两个男人），il-baab（那扇门）变 il-baabáyn（那两扇门）。如果名词以 -a 结尾，第一单元提到的“隐藏的 t”会重新出现：shárika（一家公司）变 sharikatáyn（两家公司），gúT9at láHam（一片肉）变 guT9atáyn láHam（两片肉）。如果名词以 -i 结尾，要先插入 -yy- 再加 -ayn：inglíizi（一个英国人）变 ingliiziyyáyn（两个英国人）。
رَيَّال ←→ رَيَّالَيْن
一个男人 → 两个男人
原书罗马音：rayyáal → rayyaaláyn
شَرِكَة ←→ شَرِكَتَيْن
一家公司 → 两家公司（隐藏 t 重现）
原书罗马音：shárika → sharikatáyn
إِنْجْلِيزِيّ ←→ إِنْجْلِيزِيَّيْن
一个英国人 → 两个英国人（插入 -yy-）
原书罗马音：inglíizi → ingliiziyyáyn
الْبَاب ←→ الْبَابَيْن
那扇门 → 那两扇门
原书罗马音：il-baab → il-baabáyn
双数几乎适用于所有名词，不像复数那样要死记模式，是扩大表达最快的一条捷径。

后缀式复数：-iin、-aat、-iyya

三个或以上的“复数”有两大构成方式：加后缀，或改变词内元音。先看加后缀的一类。-iin 多用于表示人的职业、身份，尤其是以 mu- 开头的词，如 mudárris → mudarrisíin（男教师→男教师们）；若单数以 -i 结尾，要先插入 -yy-，如 mikáaniki → mikaanikiyyíin。-aat 是 -iin 的阴性对应形式，用于纯女性群体：mudárrisa → mudarrisáat（女教师→女教师们），而 -iin 用于男女混合。国籍词也用这两组后缀：kuwáyti → kuwaytiyyíin（科威特人），kuwaytíyya → kuwaytiyyáat（科威特女人）。少数职业借词加 -iyya：dráywil → draywilíyya（司机）。此外，许多无生命名词（含阴性 -a 结尾词和外来借词）也用 -aat：sayyáara → sayyaaráat（汽车）、baaS → baaSáat（公共汽车）、káylo → kaylowáat（公斤）。
مُدَرِّس ←→ مُدَرِّسِين
男教师 → 男教师们（-iin）
原书罗马音：mudárris → mudarrisíin
مُدَرِّسَة ←→ مُدَرِّسَات
女教师 → 女教师们（-aat）
原书罗马音：mudárrisa → mudarrisáat
دْرَايْوِل ←→ دْرَايْوِلِيَّة
司机 → 司机们（-iyya）
原书罗马音：dráywil → draywilíyya
سَيَّانَة ←→ سَيَّالات
汽车 → 汽车（无生命名词加 -aat）
原书罗马音：sayyáara → sayyaaráat
-aat 既可表纯女性人群，也可表无生命事物；区分靠语义，不靠形式。

破碎式复数：词内元音变化

阿拉伯语最有特色的构词手段是“词根＋元音模式”。以词根 k-t-b（写）为例，套用不同元音模式可得出 kitáab（书，CiCaaC）、káatib（文书，CaaCiC）、máktab（办公室，maCCaC）、maktúub（写好的／信，maCCuuC）——词根辅音顺序始终不变。绝大多数名词的复数不是加后缀，而是给词根换一套元音模式，这就是“破碎复数”。难点在于：看单数无法预测它用哪种模式，所以最好记单词时把单复数成对记住。常见模式有：职业名词 CaCCaaC → CaCaaCiiC（farráash → faraaríish）和 CaaCiC → CuCCaaC（káatib → kuttáab）；适用于多种单数的 aCCaaC（wálad → awláad、gálam → agláam）；CuCuuC（bayt → buyúut、fils → fulúus）；以及 CaCaaCiC（dárzan → daráazin、máktab → makáatib）。
كِتَاب ←→ كُتُب
书 → 书籍
原书罗马音：kitáab → kútub
فَرّاش ←→ فَرَارِيش
仆人 → 仆人们（CaCaaCiiC）
原书罗马音：farráash → faraaríish
بَيْت ←→ بُيُوت
房子 → 房屋（CuCuuC）
原书罗马音：bayt → buyúut
وَلَد ←→ أَوْلَاد
男孩 → 男孩们（aCCaaC）
原书罗马音：wálad → awláad
把单数与复数作为一对整体记忆，比死背模式表更有效；常用模式其实数量有限，随着词汇量增大会越来越顺手。

06 文化点滴

历史（一）：葡萄牙人与海湾

最早对海湾产生兴趣的西方势力是十六世纪初的葡萄牙人。他们 chiefly 想保护通往印度和远东殖民地的新航路免受海湾海盗侵扰。整个十六世纪，他们在巴林和海湾南部修筑要塞并常年驻军，直到十七世纪中叶才被彻底逐出海湾。巴林所谓“葡萄牙堡”，其实建在更早的遗迹之上，其历史可上溯至数千年前——那时巴林受伊拉克南部的巴比伦管辖，被称作“迪尔蒙”（Dilmun）。在马斯喀特，1587 年落成的贾拉利堡（Jalali）与梅拉尼堡（Merani）至今仍扼守着旧港的入口。葡萄牙人几乎没有在海湾阿拉伯语中留下语言遗产，唯一沿用至今的葡语借词是 burtugáal（甜橙），字面意思是“葡萄牙”——海湾阿拉伯人（如今全体阿拉伯人）用它称呼葡萄牙人从阿尔加维果园带来的甜橙；而“阿尔加维”（Algarve）本身正是阿拉伯语 al-gharb“西方”的讹变。海湾更古老的“橙子”一词 naranj 是欧洲诸多语言中“orange”的词源，但在海湾它只指不可食用的苦橙，用于调味或制作果酱，也就是欧洲人所说的“塞维利亚橙”。老一辈海湾人还保留少量葡语借词：巴林旧时称桌子为 mayz（源自葡语 mesa 水桶 báaldi 是印度菜名 balti 的词源；biib 指管子、小鼓或小桶（源自葡语 pipa，英语“a pipe of port wine”里的 pipe 即此义）；gáTu 意为“猫”，二十世纪六十年代英国香烟品牌 Craven A 在海湾被称作 abu gáTu“带猫的那个”，因为烟盒上印有黑猫标志。曾经常用的葡语造船术语，如今已和相应的古老手艺一起，被收进海湾的博物馆与遗产主题公园。

延伸阅读：查尔斯·贝尔格雷夫爵士《The Pirate Coast》（G. Bell & Sons，纽约，1966）。另可留意“读阿拉伯语”一节：海湾街头（尤其餐馆）招牌常把英文直接音译成阿拉伯文，如 Hollywood 写作 هُولْيُود（双写的 l 只写一个，短元音 o 不标），saloon 写作 سَالُون（以 ص 表 s），Jolly Bee 写作 جُولِّي بِي（库法体，结尾 ي 表 ee）。

✓ 本单元小结

本单元围绕名词的三种“特指与数量”表达展开。你学会了定冠词 il，以及它在太阳字母前同化、读成长长双辅音的规则；掌握了表示“两个”的双数后缀 -ayn，以及 -a 结尾重现隐藏 t、-i 结尾插入 -yy- 的细节。你还认识了后缀式复数 -iin、-aat、-iyya 与破碎复数两大体系，并记下了一批职业、国籍和日常名词。文化点带你回顾葡萄牙人在海湾的短暂足迹和几个沿用至今的借词，练习则让你把定冠词、双数和男女命令式真正用起来。
