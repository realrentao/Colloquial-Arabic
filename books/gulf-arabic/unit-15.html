动词的派生式（一）

أَوْزَانُ الْفِعْلِ الْمُشْتَقَّةِ (١)
CaCCaC、CaaCaC、tiCaCCaC 与 tiCaaCaC 四类派生动词，以及 mi- 前缀分词
原书标题转写：awzánu l-fi9li l-mushtáqqa (1)
学习目标情景对话词汇表语法要点练习文化点滴本单元小结

01 学习目标

  • 掌握 CaCCaC（第二辅音双写）派生动词的变位、命令式与使役含义
  • 掌握 CaaCaC（首音节元音延长）派生动词及其相互、互动含义
  • 学会 tiCaCCaC 的反身/被动用法与 tiCaaCaC 的相互用法
  • 学会由 mi- 前缀构成主动分词与被动分词，并掌握 xallā 让字句

02 情景对话

活儿干完了吗？　خَلَّصْتَ الشُّغْلَ الْبَارِحَةَ؟

练习 14.3 的示例小对话：用 خَلَّصَ 的过去式询问对方昨天是否做完工作，并用分词作答。

甲
خَلَّصْتَ الشُّغْلَ الْبَارِحَةَ، مُو شِذِي؟
你昨天把活儿干完了，不是吗？
原书罗马音：xallást ish-shúghul il-báarHa, muu chidhíi?
乙
لَا، مُبْ مِخَلِّصَةٌ بَعْدُ!
不，我还没干完呢！
原书罗马音：la, mub mixálSah bá9ad!

04 语法要点

CaCCaC：第二辅音双写的派生动词

最简单的动词是三辅音词干 C1-C2-C3。本单元开始学习「派生式」：在词干中增加辅音（把第二辅音双写）或延长元音而构成的新动词。CaCCaC 就是把第二辅音双写的一类，过去式如 خَلَّصَ（完成）、بَنَّدَ（关）、بَطَّلَ（开），未完成式词干为 -CaCCiC-（يُخَلِّصُ），前缀元音永远是 i。这类动词常带使役或「致使」含义：عَلَّمَ 是「教」（使别人知道），而简单的 عَلِمَ 只是「知道」；ضَيَّعَ 是「浪费」，而简单的 ضَاعَ 是「丢失」。不过也有例外，如 حَوَّلَ 表示「下车、下来」，并没有使役义。
جَانْطَتِي ضَاعَتْ.
我的包丢了。（简单动词）
原书罗马音：jánTati Dáa9at.
لَا تُضَيِّعْ فُلُوسَكَ!
别浪费你的钱！（CaCCaC 使役义）
原书罗马音：la tiDáyyi9 flúusik!
غَيَّرُوا أَفْكَارَهُمْ.
他们改变了想法。
原书罗马音：gháyyaraw afkáarhum.
عَادَاتُكُمْ غَيْرُ عَادَاتِنَا.
你们的习俗跟我们的不一样。
原书罗马音：9aadáatkum ghayr 9aadáatna.
注意 غَيْر 意为「不同的、不同于……的」；与之对应的 CaCCaC 动词 غَيَّرَ 则是「改变、使不同」。

词干元音脱落、叠辅音还原与三种命令式

CaCCaC 的过去式变位与简单动词完全一样。未完成式中，一旦接上以元音开头的后缀（-iin、-uun，或命令式的 -i、-u），词干里的 i 就要脱落，双写的辅音也要还原成单辅音（弱动词除外）：يُخَلِّصُ + -ونَ → يُخَلِّصُونَ。同理，接以元音开头的宾语代词时也会发生脱落：يُخَلِّصُ + -ه → يُخَلِّصُهُ。弱动词则相反，词尾元音要拉长：نُسَوِّي + -ه → نُسَوِّيهِ。命令式分男、女、复数三式：بَطِّلْ!／بَطِّلِي!／بَطِّلُوا!；弱动词为 سَوِّ!／سَوِّي!／سَوُّوا!。否定命令式中，弱动词阳性例外地保留词尾 -i：لَا تَسَوِّي!。
يُخَلِّصُ + ونَ → يُخَلِّصُونَ
他完成 → 他们完成（词干 i 脱落、辅音还原）
原书罗马音：yixálliS + uun → yixalSúun
تُخَلِّصُ + ينَ → تُخَلِّصِينَ
你完成 → 你（女）完成
原书罗马音：tixálliS + iin → tixalSíin
بَطِّلْ! / بَطِّلِي! / بَطِّلُوا!
打开！（对男性／对女性／对众人）
原书罗马音：báTTil! / báTli! / báTlu!
سَوِّ! / سَوِّي! / سَوُّوا!
做！（对男性／对女性／对众人）
原书罗马音：saww! / sáwwi! / sáwwu!
لَا تَسَوِّي!
别做！（否定命令式，阳性保留 -i）
原书罗马音：la tisáwwi!
把男式、女式、复数式当成三个独立词条分别记忆和点读，考试时最易混的就是 بَطِّلْ 与 بَطِّلِي。

CaaCaC：首音节延长的派生动词

这类动词把第一个元音延长一倍：سَاعَدَ（帮助）、جَاوَبَ（回答）、سَاوَمَ（讨价还价）、قَابَلَ（会面）、لَاقَى（偶遇）、وَافَقَ（同意）。未完成式为 -CaaCiC-（يُسَاعِدُ）。其变位规律、命令式以及词干元音脱落规则都与 CaCCaC 完全相同。意义上，CaaCaC 多表示双方之间发生的动作，常带相互色彩：وَافَقَ 是「同意」，سَاوَمَ 是「讨价还价」，لَاقَى 是「（偶然）遇见」。命令式如 سَاعِدْ!／سَاعِدِي!／سَاعِدُو!，جَاوِبْ!／جَاوِبِي!／جَاوِبُو!。
وَافَقُوا عَلَى دَفْعِ الْمَبْلَغِ الْمَطْلُوبِ.
他们同意支付所要求的款项。
原书罗马音：wáafagaw 9ala daf9 il-máblagh il-maTlúub.
لَا تُسَاوِمِ مَعَهُ! يُضَيِّعُ وَقْتَكَ!
别跟他讨价还价！他会浪费你的时间！
原书罗马音：la tsáawim wiyyáah! yiDáyyi9 wáqtik!
لَاقَيْنَاهُم بِالصُّدْفَةِ فِي السُّوقِ.
我们在市场上偶然遇见了他们。
原书罗马音：laagaynáahum biS-Súdfa fis-suug.
سَاعِدْ! / سَاعِدِي! / سَاعِدُوا!
帮帮忙！（对男性／对女性／对众人）
原书罗马音：sáa9id! / sáa9di! / sáa9du!
قَابَلَ 指「预约好的会面」，لَاقَى 指「碰巧遇上」，两者中文都可译作「遇见」，但语义差别要分清。

tiCaCCaC 与 tiCaaCaC：反身、被动与相互

在 CaCCaC 和 CaaCaC 前加 ti-（或 ta-）就构成另两个派生式。tiCaCCaC 常表示相应 CaCCaC 动词的反身或被动意义：عَلَّمَ「教」→ تَعَلَّمَ「学」；ذَكَّرَ「提醒」→ تَذَكَّرَ「记起」；غَدَّى「请吃午饭」→ تَغَدَّى「吃午饭」；بَنَّدَ「关」→ تِبَنَّدَ「被关上、可关闭」。tiCaaCaC 更明确地表示相互，相当于中文的「互相、彼此」：تَوَافَقُوا「彼此达成一致」、تَقَابَلُوا「相互见面」、تَسَاعَدُوا「互相帮助」。其未完成式可表示「能够、可以被」：يَتِبَطَّلُ 既可指「打开」，也可指「被打开、能打开」。
الْكُوَيْتُ تَغَيَّرَتْ.
科威特变了。
原书罗马音：il-kuwáyt tigháyyarat.
هَذَا الصُّندُوقُ لَا يَتِبَنَّدُ.
这个箱子关不上。
原书罗马音：háadha S-Sandúug maa yitbánnad.
هَذِهِ الْعُلْبَةُ لَا يَتِبَطَّلُ.
这个罐子打不开。
原书罗马音：hal-gúuTi maa yitbáTTal.
تَوَافَقُوا عَلَى أَنَّهُمْ لَا يَتَحَارَبُونَ بَعْدُ.
他们一致同意不再互相争斗。
原书罗马音：tiwáafagaw 9ala ínnahum maa yitHaarabúun bá9ad.
لَيْشَ مَا تَتَسَاعَدُونَ؟
你们为什么不互相帮助？
原书罗马音：laysh maa titsaa9adúun?
海湾各方言对这两类的前缀元音读法不一：有的读 ta-，有的读 ti-；未完成式有的读 yit-，有的读 yti-。教材有意保留这种差异，见到不同写法不必奇怪。

mi- 前缀分词：主动式与被动式

本单元四类动词的主动态与被动态分词都以 mi- 开头，构成很有规律。CaCCaC、CaaCaC 的主动分词分别是 miCaCCiC、miCaaCiC（مُرَكِّب「正在安装的」），被动分词是 miCaCCaC、miCaaCaC（مُرَكَّب「被安装的」）。tiCaCCaC、tiCaaCaC 的主动分词是 mitCaCCiC、mitCaaCiC（مُتَغَدٍّ「正在吃午饭的」）；由于这两类动词多是不及物的，其被动分词极少使用。阴性加 -a、复数加 -iin；弱动词用 -ya、-yiin。分词后接宾语代词时，词尾 -i 要读长并带重音；所有阴性分词都有一个「隐藏的」t，接后缀时显现出来。此外，mi- 是非重读音节，在元音结尾的词之后常被省略。
مُرَكِّب / مُرَكَّب
正在安装的／已被安装的（主动／被动分词）
原书罗马音：mirákkib / mirákkab
مُتَغَدٍّ / مُتَسَاعِدٌ
正在吃午饭的／互相帮助的（ti- 型主动分词）
原书罗马音：mitgháddi / mitsáa9id
الْأُغْنِيَةُ الَّتِي يُغَنِّيهَا لَيْسَتْ حُلْوَةً.
他唱的那首歌不好听。
原书罗马音：il-úghniya ílli mghanníiha mub Hálwa.
هَذَا الرَّجُلُ الَّتِي تُحَادِثُهُ أَبُوهَا.
她正在说话的那个男人是她父亲。
原书罗马音：ir-rayyáal ílli mHáachyatah abúuha.
هَذِهِ التَّصَامِيمُ الَّتِي صَنَعَتْهَا أَعْجَبَتْنِي كَثِيرًا.
她做的这些设计让我印象很深。
原书罗马音：har-rusúum illi msawwyátta wáayid 9aajbátni.
例句里的 مُغَنِّيهَا、مُحَادِثَتَهُ、مُصَوِّيَاتُهَا 都是 mi- 前缀被省略后的写法，口语中十分常见。

xallā 让字句与 xall 祈使句

动词 خَلَّى（让、留下）后接宾语代词，再接一个未完成式动词，表示「让某人做某事」：خَلَّيْتُهُ يَسُوقُ سَيَّارَتِي 意为「我让他开我的车」；خَلَّانِي آتِي مُبَكِّرًا 意为「他让我早点来」。其否定式也很常用，还可表示「不允许某人做某事」，教材中的例子是「他不肯让我一次请那么多天假」。祈使式 خَلّْ 加代词再加未完成式动词，则表示「让我们……」，如 خَلّْنَا نَتَسَاوَمْ 意为「咱们讲价吧」。
خَلَّيْتُهُ يَسُوقُ سَيَّارَتِي.
我让他开我的车。
原书罗马音：xalláytah yisúug sayyáarti.
خَلَّانِي آتِي مُبَكِّرًا.
他让我早点来。
原书罗马音：xalláani ayíi mubákkir.
خَلّْنَا نَتَسَاوَمْ!
咱们讨价还价吧！
原书罗马音：xállna nitsáawam!
خَلّْهُمْ يَتَسَاعَدُوا فِي هَذَا الْأَمْرِ!
让他们在这件事上互相帮助吧！
原书罗马音：xállhum yitsaa9adúun fi hal-mawDúu9!
注意区分：خَلَّيْتُهُ（我让他）里的 -هُ 是宾语代词；而 خَلّْنَا（让我们）里的 -نا 同样是宾语代词，但后面直接跟复数未完成式。

06 文化点滴

风靡海湾的足球

足球是海湾地区当之无愧的第一运动。它在本地区起步于二十世纪五十年代，科威特队率先登场，并作为第一支海湾球队参加了 1982 年西班牙世界杯。此后沙特阿拉伯四度、阿联酋一度跻身世界杯决赛圈。地区性的海湾杯创办于 1970 年，首届赛事在巴林伊萨城的小球场举行，此后大致每两年一届。多年来科威特九夺桂冠，沙特阿拉伯与伊拉克各三次，卡塔尔两次，阿联酋则在 2007 年本土作战时首次捧杯——那届决赛现场六万观众目睹东道主一比零击败阿曼。海湾各国在足球上不惜重金：仅 2007 年海湾杯开幕式就耗资三千三百万阿联酋迪拉姆，还常常高薪延请外籍名帅。七十年代初那支所向披靡的科威特队至今仍被奉为传奇，他们在前六届海湾杯中五度夺冠，1982 年世界杯上逼平捷克斯洛伐克、惜败英格兰和法国；队中中锋贾西姆·雅库布人称「黑珍珠」，门将艾哈迈德·塔拉布勒西更是罕见的天才，这位巴勒斯坦出生的球员被特批入籍科威特，得以代表国家队出战。

海湾足球术语大量借自英语：gool（进球，源自 goal，如 jaab gooláyn「他进了两个球」）、baas（传球，源自 pass）、bílanti（点球，源自 penalty）、kúrnar（角球，源自 corner）。有意思的是，电视解说员在已经用阿拉伯语 bárra（出界）说完之后，往往还要再补一个英语借词 awt（out），这也是海湾口语「阿拉伯语打底、英语添味」的生动写照。

✓ 本单元小结

本单元系统学习了阿拉伯语动词的四个派生式：CaCCaC（第二辅音双写，常带使役义）、CaaCaC（首音节延长，多表双方互动）、tiCaCCaC（反身或被动）与 tiCaaCaC（相互）。你掌握了它们的变位规律，尤其是词干元音 i 在接元音后缀时脱落、叠辅音随之还原的规则，以及男、女、复数三种命令式的不同写法。我们还学习了 mi- 前缀的主动与被动分词，以及 خَلَّى＋代词＋未完成式表示「让某人做某事」、خَلّْ＋代词表示「咱们……吧」的句型。文化点部分则带你了解了风靡海湾的足球运动，以及其中大量来自英语的球场借词。
