第 11 单元 · 初级

一直往前走！

عَلَى طُول!
城里问路指路、发出指令与动词分类
原书标题转写：9ála Tuul!
学习目标情景对话词汇表语法要点练习文化点滴本课字母本单元小结

01 学习目标

  • 说出城里常见场所的名称
  • 听懂并说出方向与路线
  • 学会用命令式发出指令、劝阻别人
  • 辨别规则动词与三类不规则动词
  • 认识字母 واو，并弄懂长元音在阿拉伯文里怎么写

02 情景对话

对话一 · 别担心，夫人　مَا تِخَافِيش يَا مَدَام

易卜拉欣打电话到办公室找薇达德，商量劳伦斯先生的出行计划：他想独自进城，去博物馆和车站。

易卜拉欣
أَلُو؟ أَيْوَا يَا مَدَام، أَنَا إِبْرَاهِيم.
喂？是的，夫人，我是易卜拉欣。
原书罗马音：aló? áywa yaa madáam, ána ibrahíim.
易卜拉欣
دَه مِسْتَر لُورَانْس عَاوِز يِنْزِل وُسْط الْبَلَد لِوَحْدُه.
这位劳伦斯先生想一个人到市中心去。
原书罗马音：da 'mister Laurence' 9áawiz yínzil wusT il-bálad li-wáHduh.
薇达德
لِيهْ يَا إِبْرَاهِيم؟
这是为何呀，易卜拉欣？
原书罗马音：leh yaa ibrahíim?
易卜拉欣
بِيِقُول عَاوِز يِرُوح مِيدَان التَّحْرِير عَشَان يِزُور الْمَتْحَف وَبَعْدَيْن عَاوِز يِنْزِل مَحَطِّت رَمْسِيس عَشَان يِحْجِز فِي قَطْر لُقْصُر.
他说想去解放广场参观博物馆，接着还要去拉美西斯车站，订开往卢克索的火车票。
原书罗马音：bi-yi'úul 9áawiz yirúuH miidáan it-taHríir 9asháan yizúur il-mátHaf wi-ba9dáyn 9áawiz yínzil maHáTTit ramsíis 9asháan yíHgiz fi 'aTr lú'Sur.

原书罗马音：il-mátHaf wil-maHáTTa? akháaf laytúuh yaa ibrahíim.
易卜拉欣
مَا تِخَافِيش يَا مَدَام.
您别担心，夫人。
原书罗马音：ma tikhafíish yaa madáam.
易卜拉欣
أَنَا حَوْصِف لُه السِّكَّة كُوَيِّس.
我会把路线给他讲得清清楚楚。
原书罗马音：ána HawSíf luh is-sikka kwáyyis.

04 语法要点

动词分几类：规则与三类不规则

规则动词有三个始终读得出来、固定不变的根辅音；最基本的一类，现在／将来时在第二、三根字母之间加一个元音，如 يِحْجِز、يُخْرُج、يِنْزِل。不规则多半出在词根里带 واو、ياء 或 همزة 时——这些字母会化成元音，从而改变词干格式，主要有三类：① 词干以长元音开头（首根为 hamza），如 يَاكُل、يَاخُد，此时人称前缀缩成 y-、t-、n-，第一人称索性不加前缀（آكُل、آخُد）；② 词干中间是长元音的「中空动词」，如 يِرُوح、يِزُور、يِزِيد、يِنَام，重音落在长元音上；③ 词干以元音收尾的「缺尾动词」，如 يِصْحَى、يِبْقَى，加后缀前要把词尾元音删掉。
يِحْجِز / يُخْرُج / يِنْزِل
预订（H/g/z）／出门（kh/r/g）／下去、下车（n/z/l）
原书罗马音：yíHgiz / yúkhrug / yínzil
يَاخُد / تَاخُد / نَاخُد / آخُد
他拿／她拿／我们拿／我拿
原书罗马音：yáakhud / táakhud / náakhud / áakhud
تَاخْدِي / يَاكْلُو
你（女）拿／他们吃（长元音缩短，第二个元音脱落）
原书罗马音：tákhdi / yáklu
يِرُوح / يِزُور / يِزِيد / يِنَام
去／参观／增加／睡觉（中空动词）
原书罗马音：yirúuH / yizúur / yizíid / yináam
يِصْحَى / يِصْحُو / تِصْحِي
他醒来／他们醒来／你（女）醒来（缺尾动词）
原书罗马音：yíSHa / yíSHu / tíSHi
يِبْقَى

原书罗马音：yíb'a
给中国学习者：判断口诀——先找三个根辅音；若中间或末尾出现长元音，就往「中空」「缺尾」上想。中空动词的重音一定落在那个长元音上，可与 يِنْزِل、يُخْرُج 对比着念。

命令式：怎样发指令

发指令要用命令式。规则动词和缺尾动词：拿现在时的「你」形式，去掉开头的 t- 即可，如 تِنْزِل ➞ اِنْزِل、تِنْزِلِي ➞ اِنْزِلِي、تِنْزِلُو ➞ اِنْزِلُو。中空动词和以长元音开头的动词：把 t- 连同它后面的元音一起去掉，如 تِرُوح ➞ رُوح、تَاخُد ➞ خُد。要留意：阴性、复数命令式里，中间那个元音会重新冒出来——تَاخْدِي ➞ خُدِي，تَاكْلُو ➞ كُلُو。对话二里的 خَلِّي（一直保持！）属于另一类动词，先认得就行，第 13 单元再细讲。

中国学习者最容易错在阴性、复数：别简单照搬阳性命令式，要记得把中间元音补回来（خُد ← خُدِي ← خُدُو）。

否定指令：两种说法，都用现在动词

劝阻别人也有两套办法，特别要记牢：两种都用现在动词，而不是命令式。① 用 مَا … -ش 把现在动词夹在中间，重音移到最后一个音节：مَا تِنْزِلْش!、مَا تُخْرُجِيش!、مَا تَاخْدُوش!。② 在现在动词前面直接加 بَلاش：بَلاش تِنْزِل!、بَلاش تُخْرُجِي!、بَلاش تَاخْدُو!。意思一样，可以换着用。
مَا تِنْزِلْش! / بَلاش تِنْزِل!
别下去！（对男性）
原书罗马音：ma tinzílsh! / baláash tínzil!
مَا تُخْرُجِيش! / بَلاش تُخْرُجِي!
别出门！（对女性）
原书罗马音：ma tukhrugísh! / baláash tukhrúgi!
مَا تَاخْدُوش! / بَلاش تَاخْدُو!
别拿！（对众人）
原书罗马音：ma takhdúsh! / baláash tákhdu!
مَا تِطْلَعْش كُوبْرِي سِتَّة أُكْتُوبِر. / بَلاش تِطْلَع كُوبْرِي سِتَّة أُكْتُوبِر.
别上十月六日大桥。
原书罗马音：ma tiTlá9sh kúbri sítta oktúubir. / baláash tíTla9 kúbri sítta oktúubir.
和第 10 单元的否定对照记：名词句、形容词用 مِش；动词句用 مَا … -ش；而「命令别人别做」虽然也用 مَا … -ش，后面跟的却是现在动词，不是命令式。

问路与指路的固定说法

问路最实用的句式是「地名 + مِنَيْن؟」（……怎么走？字面「从哪儿？」），前面加上 لَوْ سَمَحْت!（劳驾，对男性）或 لَوْ سَمَحْتِي!（对女性）更得体。指路时常用的词有 خَلِّيك（一直保持）、خُد（往……拐）、دُغْرِي / عَلَى طُول（照直走）、عَلَى الشِّمَال / عَلَى الْيَمِين（在左／右边）；再用 أَوَّل、تَانِي、تَالِت 说明是第几个路口、第几座桥、第几组红绿灯。
لَوْ سَمَحْت، الْكُوبْرِي مِنَيْن؟
劳驾，大桥怎么走？
原书罗马音：law samáHt, il-kúbri mináyn?
لَوْ سَمَحْتِي، الْمَتْحَف مِنَيْن؟
（问女性）劳驾，博物馆怎么走？
原书罗马音：law samáHti, il-mátHaf mináyn?
خَلِّيك دُغْرِي عَلَى الْكُورْنِيش.
沿滨河大道一直往前。
原书罗马音：khallíik dúghri 9ála k-korníish.
خُد شِمَال عَنْد الْهِلْتُون.
到希尔顿往左拐。
原书罗马音：khud shimáal 9and il-Hilton.
حَتْلاقِي الْمَتْحَف عَلَى الْيَمِين.
你会看到博物馆在右手边。
原书罗马音：Ha-tiláa'i l-mátHaf 9ála l-yimíin.
مَدْخَل الْمَحَطَّة بَعْد تَانِي إِشَارَة تَحْت الْكُوبْرِي.
车站入口在桥下第二个红绿灯之后。
原书罗马音：mádkhal il-maHáTTa ba9d táani isháara taHt ik-kúbri.
序数词别死记：أَوَّل شَارِع（第一条街）、تَانِي إِشَارَة（第二个红绿灯）、تَالِت كُوبْرِي（第三座桥）——把教材第 199 页这组短语整组背下来最省力。

说「我想去……」：9áawiz / 9áwza + 动词

想表达「我想去／想参观／想在……吃饭」，用 عَاوِز（男性说自己）或 عَاوْزَة（女性说自己），后面再接一个动词：أَرُوح（我去）、أَزُور（我参观）、آكُل فِي（我在……吃）。换成别的主语时，عَاوِز 要跟着变性数（复数 عَاوْزِين），后面的动词也换成相应人称。
أَنَا عَاوِز أَرُوح الْمَسْرَح فِي وُسْط الْبَلَد.
我想去市中心的剧院。
原书罗马音：ána 9áawiz arúuH il-másraH fi wusT il-bálad.
أَنَا عَاوْزَة أَزُور الْمَتْحَف.
我想参观博物馆。
原书罗马音：ána 9áwza azúur il-mátHaf.
إِحْنَا عَاوْزِين نِرُوح الْمَسْرَح فِي وُسْط الْبَلَد.
我们想去市中心的剧院。
原书罗马音：íHna 9awzíin nirúuH il-másraH fi wusT il-bálad.
هُوَّ عَاوِز يِرُوح مِيدَان التَّحْرِير.
他想去解放广场。
原书罗马音：húwwa 9áawiz yirúuH miidáan it-taHríir.
عَاوِز 是主动分词，所以有阴阳性和复数；后面的动词才是真正带人称的那个，别把两处都变了又或一处都不变。

阿拉伯文里长元音怎么写

短元音（a、i、u 等）在真正的阿拉伯文里通常不写出来，熟练的读者凭上下文自己补；本教材为方便初学者才通篇标了元音。长元音则必须写出来，由 و、ا、ي 三个字母充当：و 表 ū 或 ō，ا 表 ā，ي 表 ī 或 ay。这三个字母本身又能当辅音（w、y 或 همزة 的载体），要看它在词里的位置来判断。
يِرُوح / يَوْم
去／天（و 分别读 ū 与 ō）
原书罗马音：yirúuH / yohm
يِنَام / غَاوِي
睡觉／热衷的（ا 读 ā）
原书罗马音：yináam / gháawi
عَصِير / بَيْت
果汁／房子（ي 分别读 ī 与 ay）
原书罗马音：9aSíir / bayt
وَاحِد / قَوِي
一／很（و 作辅音 w）
原书罗马音：wáaHid / 'áwi
给中国学习者：本教材的元音符号是「学步车」，真正的报刊、招牌、路牌是不标的。练到一定程度，要试着脱开元音符号，靠 و、ا、ي 和词型把长音读出来。

06 文化点滴

跟着地标走：开罗人的指路方式

本单元的两段对话，简直是一张开罗市中心地图：解放广场（مِيدَان التَّحْرِير）旁的埃及博物馆、拉美西斯车站（مَحَطِّت رَمْسِيس）、十月六日大桥（كُوبْرِي سِتَّة أُكْتُوبِر）、作为醒目路标的开罗塔（الْبُرْج）、沿尼罗河的滨河大道（الْكُورْنِيش）与希尔顿饭店，还有车站入口附近那家卖蚕豆与炸豆丸子三明治的名店「阿布·瓦尔达」（أَبُو وَرْدَة）。埃及人指路习惯说「过了塔再下来」「希尔顿那儿往左拐」「桥下第二个红绿灯后面」，靠地标和相对位置，而不是报门牌号。فُول（蚕豆）与 طَعْمِيَّة（炸豆丸子）正是埃及最家常的街头吃食。

给中国学习者：初到开罗，先把几个大地标的名字记熟，问路、听指路都会轻松很多；遇到「تَانِي إِشَارَة（第二个红绿灯）」「تَحْت الْكُوبْرِي（桥底下）」这类说法，要按地标去理解，别急着找门牌。另外，问路前别忘了先说一句 لَوْ سَمَحْت / لَوْ سَمَحْتِي，比直接发问更礼貌。

07 本单元所学字母

و
瓦乌　وَاو
作辅音时读 w（如 window 的 w）；作长元音时读 ū（如 boot）或 ō（如 toe、boat）

✓ 本单元小结

本单元我们学会在城里问路、指路：一句「地名 + مِنَيْن؟」配上 لَوْ سَمَحْت 就能开口，再用 خَلِّيك、خُد、دُغْرِي、عَلَى الْيَمِين 把路线说清楚。语法上，我们分清了规则动词与三类不规则动词，掌握了命令式的构成（去掉 t-，以及阴性复数里元音的回归），并用 مَا … -ش 与 بَلاش 两种办法劝阻别人；还学会了用 عَاوِز / عَاوْزَة 说「我想去……」。书写方面认识了字母 واو，明白了短元音通常不写、长元音要靠 و、ا、ي 写出来。
