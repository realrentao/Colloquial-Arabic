第 2 单元 · 入门

我的家庭

عِيلْتِي
家庭成员、复数代词与所属关系
原书标题转写：9ílti
学习目标情景对话词汇表语法要点练习文化点滴本课字母本单元小结

01 学习目标

  • 学会称呼各类家庭成员
  • 掌握复数人称代词「我们、你们、他们」
  • 用接尾代词表达「我的、你的、我们的」等所属关系
  • 辨别名词的阴阳性
  • 用 da / di / duul 和疑问词提出简单问句
  • 认读字母 ن、ي，并拼读几个简单的阿拉伯文单词

02 情景对话

对话一 · 快过来！　تَعَالَى!

萨米拉是塞得港人，今天在开罗参加一场「突击」学生广播问答，家人都留在老家。听录音判断：哈桑是萨米拉的什么人？

萨米拉的母亲
يَا حَسَن! تَعَالَى! أُخْتَك فِي الرَّادْيُو!
哈桑！快过来！你姐姐上广播啦！
原书罗马音：yaa Hásan! ta9áala! úkhtak fir-rádyo!
哈桑
أُخْتِي؟
我姐姐？
原书罗马音：úkhti?
萨米拉的母亲
بِسُرْعَة. قُول لِأَبُوك تَعَالَى!
快点！叫你爸爸过来！
原书罗马音：bi-súr9a. ’uul l-abúk ta9áala!
哈桑
بَابَا! بَابَا! تَعَالَى إِسْمَع بِنْتَك فِي الرَّادْيُو!
爸爸！爸爸！快来听你女儿上广播！
原书罗马音：bába! bába! ta9áala ísma9 bíntak fir-rádyo!
萨米拉的父亲
بِنْتِي؟ هَات الرَّادْيُو هِنَا يَا حَسَن يَبْنِي.
我女儿？哈桑，我的孩子，把收音机拿到这儿来。
原书罗马音：bínti? haat ir-rádyo hína yaa Hásan yábni.
萨米拉的母亲
لَأْ. إِحْنَا هِنَا! تَعَالَى إِنْتَ لِلرَّادْيُو!
别，我们在这儿呢！你自己到收音机这边来！
原书罗马音：la’. íHna hína! ta9áala ínta lir-rádyo!

对话二 · 这是谁？　مِين دِي؟

贾比尔给朋友哈桑看家庭相册里的一张照片。听录音回答：照片里的姑娘是谁？那位年长的男子是谁？照片是在哪儿拍的？

哈桑
مِين دِي يَا جَابِر؟
贾比尔，这是谁？
原书罗马音：miin di yaa gáabir?
贾比尔
دِي خَطِيبْتِي وِدَاد.
这是我的未婚妻薇达德。
原书罗马音：di khaTíbti widáad.
哈桑
وَإِمْتَى الْفَرَح إِنْ شَاءَ اللَّهُ؟
那婚礼定在什么时候，托靠主愿？
原书罗马音：w-ímta l-fáraH in sháa’ alláah?
贾比尔
الْفَرَح فِي الصَّيْف.
婚礼在夏天。
原书罗马音：il-fáraH fiS-Sayf.
哈桑
وَدَا مِين؟
那这位又是谁？
原书罗马音：wi-da miin?
贾比尔
دَا خَالِي أَمِين بِتَاع أُوسْتُورَالْيَا.
那是我舅舅阿明，在澳大利亚的那位。
原书罗马音：da kháali amíin bitáa9 ostorálya.
哈桑
وَالصُّورَة دِي فَيْن يَا جَابِر؟
贾比尔，这张照片是在哪儿拍的？
原书罗马音：wiS-Súura di fayn yaa gáabir?
贾比尔
شَرْم الشَّيْخ.
沙姆沙伊赫。
原书罗马音：sharm ish-shaykh.

对话三 · 萨米拉介绍她的家人　أَنَا إِسْمِي سَمِيرَة

教材第 32 页练习六的听力原文：看着萨米拉的家谱，听她介绍自己的家人。家谱上还有父亲 9osmáan、母亲 láyla、哥哥 Hásan。

萨米拉
أَنَا إِسْمِي سَمِيرَة وَأَنَا مِنْ بُور سَعِيد.
我叫萨米拉，来自塞得港。
原书罗马音：ána ísmi samíira w-ána min buur sa9íid.
萨米拉
أَخُويَا إِسْمُه حَسَن وَأُمِّي إِسْمَاهَا لَيْلَى.
我哥哥叫哈桑，我妈妈叫莱拉。
原书罗马音：akhúya ísmuh Hásan w-úmmi ism(á)haa láyla.
萨米拉
بَابَا … أَبُويَا … إِسْمُه عُثْمَان.
爸爸……我父亲……叫奥斯曼。
原书罗马音：bába … abúya … ísmuh 9osmáan.

04 语法要点

复数人称代词：我们、你们、他们

上一单元学了单数代词，这里再补三个复数：إِحْنَا 我们、إِنْتُو 你们、هُمَّا 他们。要记住「你」始终有三个说法：إِنْتَ 对男性、إِنْتِ 对女性、إِنْتُو 对一群人。教材练习二就是把「我＋某某」「你＋你」这类并列主语，干脆换成一个复数代词来说。
أَنَا وَسَمِيرَة هِنَا! ➞ إِحْنَا هِنَا!
我和萨米拉在这儿！→ 我们在这儿！
原书罗马音：ána wi-samíira hína! ➞ íHna hína!
هُوَّ وَمِرَاتُه هِنَا؟ ➞ هُمَّا هِنَا؟
他和他妻子在吗？→ 他们在吗？
原书罗马音：húwwa wi-miráatuh hína? ➞ húmma hína?
إِنْتَ وَإِنْتِ فِي الرَّادْيُو! ➞ إِنْتُو فِي الرَّادْيُو!
你（男）和你（女）上广播了！→ 你们上广播了！
原书罗马音：ínta w-ínti fir-rádyo! ➞ íntu fir-rádyo!
أَنَا وَجُوزِي مِنْ إِسْكَنْدَرِيَّة. ➞ إِحْنَا مِنْ إِسْكَنْدَرِيَّة.
我和我丈夫来自亚历山大。→ 我们来自亚历山大。
原书罗马音：ána wi-góhzi min iskindiríyya. ➞ íHna min iskindiríyya.
汉语的「你」不分单复数，阿语却要三选一。把「A 和 B」直接压缩成一个复数代词，是埃及口语很自然、也很省事的说法。

家庭称谓与所属：不加「的」直接连

要说「某人的妈妈」「莱拉的丈夫」，把家庭成员词直接放在名字或接尾代词前面就行，不需要相当于汉语「的」的词。两个细节要记：أَب（父亲）与 أَخ（兄弟）后面接名字或接尾代词时，要变成 أَبُو、أَخُو；若两词相连会撞出三个辅音，中间得插一个「帮助元音」，教材在前几单元用括号标出，如 umm(i) samíira。
جُوز لَيْلَى
莱拉的丈夫
原书罗马音：gohz láyla
وِلَاد أَحْمَد
艾哈迈德的孩子们
原书罗马音：wiláad áHmad
أُخْتَك / مِرَاتِي
你的姐姐（对男性说）／我的妻子
原书罗马音：úkhtak / miráati
أَبُو جَابِر / أَخُو سَمِيرَة
贾比尔的父亲／萨米拉的哥哥
原书罗马音：ábu gáabir / ákhu samíira
أُمِّ سَمِيرَة
萨米拉的母亲（插入帮助元音 i）
原书罗马音：umm(i) samíira
记牢「家庭词 ＋ 名字／接尾代词」这个顺序，别把「的」硬塞进去。أَب→أَبُو、أَخ→أَخُو 这两处变形最容易被漏掉，可和 أُمِّ سَمِيرَة 的帮助元音一起记。

接尾代词：辅音收尾与元音收尾的两套形式

表示「我的、你的、我们的」的接尾代词，加在以辅音收尾的词（如 وِلَاد）和以元音收尾的词（如 أَبُو）上时，形式略有差别：后一类要去掉一个元音，或用 -ya 表示「我的」。若加了词尾后出现三个辅音相连，同样要插帮助元音，而且重音会落到这个帮助元音上——教材特别提醒，重音总爱停在倒数第二个音节。
وِلَادِي / وِلَادَك / وِلَادِك
我的／你的（男）／你的（女）孩子们
原书罗马音：wiláadi / wiláadak / wiláadik
وِلَادُه / وِلَادْهَا
他的／她的孩子们
原书罗马音：wiláaduh / wiláadhaa
وِلَادْنَا / وِلَادْكُو / وِلَادْهُم
我们的／你们的／他们的孩子们
原书罗马音：wiláadna / wiláadku / wiláadhum
أَبُويَا / أَبُوك / أَبُوكِي
我的／你的（男）／你的（女）父亲
原书罗马音：abúya / abúk / abúki
بِنْتِنَا / إِسْمَاهَا
我们的女儿／她的名字（含帮助元音）
原书罗马音：bint(í)na / ism(á)haa
把表拆成两栏记：辅音收尾用 -i、-ak、-ik、-uh、-haa、-na、-ku、-hum；元音收尾（أَبُو 一类）用 -ya、-k、-ki、-h、-haa、-na、-ku、-hum。对比 إِسْمُه 与 إِسْمَاهَا、إِزَّيُّه 与 إِزَّيَّاهَا，就能听出重音怎么被推开。

名词的阴阳性

阿拉伯语名词非阳即阴，判别其实很简单：几乎全部阴性名词以 -a 收尾，阳性名词则不然。少数例外是不以 -a 收尾、却指女性或国家城市的词，例如 أُمّ（母亲）、بِنْت（女儿）、مَصْر（埃及）。这条规律还能顺带决定冠词、指示词和接尾代词该用哪种形式。
فَرَح / رَادْيُو
婚礼／收音机（均阳性）
原书罗马音：fáraH / rádyo
صُورَة / خَالَة
照片／姨妈（均阴性，以 -a 收尾）
原书罗马音：Súura / kháala
أُمّ / بِنْت / مَصْر
母亲／女儿／埃及（不以 -a 收尾，仍属阴性）
原书罗马音：umm / bint / maSr
见到词尾 ة 或 -a 先当阴性，八九不离十。阴性词加接尾代词时，-a 还会变成 -t 或 -it（如 صُورَة ➞ صُورْتَك、صُورِتْنَا），这是本单元后半的重点。

冠词 il、太阳字母与元音后的连读

特指用 il- 表示，阿语里没有不定冠词。有一批起首字母会让冠词的 ل 同化：ل 不发音，后面的字母叠读。这类字母叫「太阳字母」——因为阿语里「太阳」一词 شَمْس 本身就以会发生同化的 ش 起首。教材列出的太阳字母是 t、d、z、n、r、s、sh、S、T、D、Z、l，k 和 g 在埃及口语里有时也算。另外，il- 若跟在以元音收尾的词后，冠词的 i 会脱落，与前面的元音连读，如 fi + iS-Sayf 读成 fiS-Sayf。
صُورَة ➞ الصُّورَة
一张照片 → 那张照片
原书罗马音：Súura ➞ iS-Súura
رَادْيُو ➞ الرَّادْيُو
一台收音机 → 那台收音机
原书罗马音：rádyo ➞ ir-rádyo
بِنْت ➞ الْبِنْت / فَرَح ➞ الْفَرَح
女孩 → 那个女孩／婚礼 → 那场婚礼
原书罗马音：bint ➞ il-bint / fáraH ➞ il-fáraH
إِمْتَى الْفَرَح؟
婚礼在什么时候？（íl 前的 i 脱落）
原书罗马音：ímta l-fáraH?
فِي الصَّيْف / وَالْوِلَاد
在夏天／和孩子们
原书罗马音：fiS-Sayf / wil-wiláad
初学不必紧张：就算在太阳字母前老老实实读成 il，埃及人也听得懂，慢慢养成叠读习惯就好。书写上仍把 ال 完整写出来，只是 ل 不发音、后面的字母带 شَدَّة。

指示词 da / di / duul，以及怎样提问

埃及口语不分「这」与「那」、「这些」与「那些」，但指示词要随所指对象的阴阳性、单复数变化：阳性用 دَا、阴性用 دِي、复数用 دُول。它们可以直接构成没有系词的句子和问句。若想说「这场婚礼」而不是「这是婚礼」，得先给名词加冠词，再把指示词放在后面。另外阿语没有专门的疑问句式，句末语调一扬即可；مِين、فَيْن、إِمْتَى 等疑问词位置灵活，常放在句末。
دِي صُورَة. / دَا خَالِي.
这是一张照片。／这是我舅舅。
原书罗马音：di Súura. / da kháali.
مِين دِي؟ / مِين دُول؟
这是谁（女）？／这些是谁？
原书罗马音：miin di? / miin duul?
الْفَرَح دَا / الصُّورَة دِي / الْوِلَاد دُول
那场婚礼／这张照片／那些孩子
原书罗马音：il-fáraH da / iS-Súura di / il-wiláad duul
هُوَّ مِنْ بُور سَعِيد. / هُوَّ مِنْ بُور سَعِيد؟
他来自塞得港。／他来自塞得港吗？
原书罗马音：húwwa min buur sa9íid. / húwwa min buur sa9íid?
مِين دَا؟ / دَا مِين؟
那是谁？（疑问词前后皆可）
原书罗马音：miin da? / da miin?
「这／那」不分，是中文学习者最容易想多的地方：别费劲找「远称近称」，把力气花在 دَا / دِي / دُول 的阴阳性、单复数上更划算。

06 文化点滴

红海之滨的度假胜地

埃及红海沿岸是本国人与外国游客都钟爱的度假地，以丰富的海洋生物、绵长的沙滩和终年不断的阳光闻名。自 1980 年代初以来，红海边度假村的数量与规模一路激增；名气最大的几处包括西奈半岛上的沙姆沙伊赫（sharm ish-shaykh）与达哈卜（dáhab），以及西岸的赫尔格达（ghardá’a）与艾因苏赫纳（il-9ayn is-súkhna）。教材还提示读者，可以下载更多介绍红海度假地的资料。

给中国学习者：这些地名在埃及新闻、旅游广告里出现频率很高。本单元对话二里，贾比尔给哈桑看的那张照片正是在 شَرْم الشَّيْخ 拍的；读到文化点时不妨回头对照单元开头那张地图，把埃及主要城市与红海度假地的位置一起记下来。

✓ 本单元小结

本单元我们学会了称呼家庭成员，并用「家庭词＋名字／接尾代词」直接表达所属，不必加「的」；记住了 أَب→أَبُو、أَخ→أَخُو 的变形和三辅音相连时的帮助元音。语法上掌握了 إِحْنَا、إِنْتُو、هُمَّا 三个复数代词、两套接尾代词表，分清了名词的阴阳性，学会了定冠词 il- 与太阳字母的叠读，也学会用 دَا / دِي / دُول 指人指物、用升调或 مِين / فَيْن / إِمْتَى 提问。文化上认识了红海沿岸的度假胜地，书写上新学了 ن 与 ي 两个字母，并弄明白短元音在书面阿拉伯语里通常省略。
