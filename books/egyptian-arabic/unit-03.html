第 3 单元 · 入门

喝点茶好吗？

تِشْرَب شَاي؟
待客、点餐与职业
原书标题转写：tíshrab shay?
学习目标情景对话词汇表语法要点练习文化点滴本课字母本单元小结

01 学习目标

  • 学会向客人敬茶敬食，并留意对女性说话时的词尾变化
  • 礼貌地接受或婉拒招待，并会说明缘由
  • 说出常见的埃及饮品与菜肴
  • 用 عَنْد 表示「有」，用正偏组合表达「……的……」
  • 谈论职业、把词变成复数，并用 مِش 构成否定句
  • 辨清 ح、ج、خ 三个同骨架字母

02 情景对话

对话一 · 喝点茶好吗？　تِشْرَب شَاي؟

贾比尔的母亲趁哈桑等朋友准备的当儿，端来早点点心招待他。听录音回答：主人给哈桑端的是茶还是咖啡？他有没有接受那碗甜粥？

贾比尔的母亲
تِشْرَب شَاي يَبْنِي؟
孩子，喝点茶好吗？
原书罗马音：tíshrab shay yábni?
哈桑
لَأْ شُكْرًا يَا طَنْط. لِسَّة شَارِب.
不用了，谢谢阿姨，我刚喝过。
原书罗马音：la’ shukrán yaa Tant. líssa sháarib.
贾比尔的母亲
تَاكُل طَبَق بِلِيلَة؟
来一碗甜粥好吗？
原书罗马音：tákul Tába’ bilíila?
哈桑
بِلِيلَة؟ أَنَا أَمُوت فِي الْبِلِيلَة!
甜粥？我可爱死甜粥了！
原书罗马音：bilíila? ána amúut fil-bilíila!
贾比尔的母亲
طَيِّب، أُقْعُد يَبْنِي!
那好，孩子，快坐下吧！
原书罗马音：Táyyib, u’9úd yábni!

04 语法要点

敬食敬饮的三种问法，以及阴性词尾 -i

招待客人最常用三个问句：تِشْرَب …؟（喝点……吗）、تَاكُل …؟（吃点……吗），以及不限吃喝、更笼统的 تِحِبّ …؟（想要……吗）。对女性说话，动词要加阴性词尾 -i；这一加，读音会跟着变：تِشْرَب ➞ تِشْرَبِي（重音往后移），تَاكُل ➞ تَاكْلِي（u 整个脱落）。这类变化是埃及口语的典型特征，听录音时要特别留心。
تِشْرَب شَاي؟ / تِشْرَبِي شَاي؟
喝点茶吗？（对男／对女）
原书罗马音：tíshrab shay? / tishrábi shay?
تَاكُل طَبَق بِلِيلَة؟ / تَاكْلِي طَبَق بِلِيلَة؟
来碗甜粥吗？（对男／对女）
原书罗马音：tákul Tába’ bilíila? / tákli Tába’ bilíila?
تِحِبِّي مَصْرِي؟
您想吃埃及菜吗？（对女性）
原书罗马音：tiHíbbi máSri?
给中国学习者：别只把 -i 当成「多加一个尾音」，它会连重音、甚至元音一起改掉。تَاكُل ➞ تَاكْلِي 里 u 直接消失，是最容易读错的一处。

礼貌地接受与婉拒

最简单的回答是 أَيْوَا، مِنْ فَضْلَك（好，麻烦了；对女性改说 مِنْ فَضْلِك）与 لَأْ، شُكْرًا（不用了，谢谢）。婉拒时最好补一句理由，免得拂了主人盛情；最常说的就是「我刚吃过／刚喝过」——لِسَّة 意为「刚刚」，后面接 شَارِب（喝着）、وَاكِل（吃着）这类主动分词，教材说更系统的讲法留到第 4 单元。女性说话要改用 شَرْبَة、وَكْلَة。
أَيْوَا، مِنْ فَضْلَك.
好的，麻烦了。（对男性）
原书罗马音：áywa, min fáDlak.
أَيْوَا، مِنْ فَضْلِك.
好的，麻烦了。（对女性）
原书罗马音：áywa, min fáDlik.
لَأْ شُكْرًا. لِسَّة شَارِب.
不用了，谢谢，我刚喝过。
原书罗马音：la’, shukrán. líssa sháarib.
لَأْ شُكْرًا. لِسَّة وَكْلَة.
不用了，谢谢，我刚吃过。（女性）
原书罗马音：la’, shukrán. líssa wákla.
中文里说「不吃了」很自然，埃及人却习惯附带一句解释。把 لِسَّة شَارِب / لِسَّة وَاكِل 当现成套语背下来，比临场组织句子管用得多。

用 عَنْد 表示「有」

阿语没有单独的「有」动词，而是用 عَنْد（字面「在……那儿」）加接尾代词来表达：عَنْدِي 我有、عَنْدَك 你有，等等。需要帮助元音时重音会移动，始终落在倒数第二个音节。这些短语既能单独成句，也能和名词、主语代词连用。
عَنْدِي / عَنْدَك / عَنْدِك
我有／你有（男）／你有（女）
原书罗马音：9ándi / 9ándak / 9ándik
عَنْدُه / عَنْدَاهَا
他有／她有
原书罗马音：9ánduh / 9andáhaa
عَنْدِنَا / عَنْدُكُو / عَنْدُهُم
我们有／你们有／他们有
原书罗马音：9andína / 9andúku / 9andúhum
عَنْدِنَا وَرَق عِنَب.
我们有葡萄叶卷。
原书罗马音：9andína wára’ 9ínab.
أَنَا عَنْدِي أُخْت إِسْمَاهَا مُونَا.
我有个姐姐叫莫娜。
原书罗马音：ána 9ándi ukht ismáhaa móna.
对照第 2 单元的接尾代词表，عَنْد 用的正是同一套词尾；重音规律和 إِسْمَاهَا 完全一致，可以合并着记。

正偏组合 iDáafa：两个名词直接相连

把两个名词直接并在一起，就能表达「……的……」：一碗甜粥、薇达德的父亲、卡迈勒的沙拉。阿语称这种结构为 إِضَافَة（iDáafa，字面「附加」），词序和汉语相反——先在心里补一个「的」就好记了。三个要点：首词不带冠词；阴性词尾 -a 处在首词时要变成 -it；若整个组合是确指的，冠词只加在第二个名词上。
أَبُو وِدَاد
薇达德的父亲
原书罗马音：ábu widáad
سَنْدَوِتْش طَعْمِيَّة
一个炸豆饼三明治
原书罗马音：sandawítsh Ta9míyya
طَبَق بِلِيلَة
一碗甜粥
原书罗马音：Tába’ bilíila
سَلَطِت سَبَانِخ / صُورِت بِنْتِي
菠菜沙拉／我女儿的照片
原书罗马音：sálaTit sabáanikh / Súurit bínti
طَبَق الْبِلِيلَة / طَبَق الْيَوْم
那碗甜粥／今日例菜
原书罗马音：Tába’ il-bilíila / Tába’ il-yohm
最容易错的是冠词位置：说「那碗粥」，ال 只加在 بِلِيلَة 上，طَبَق 前绝不能加。阴性首词的 -a ➞ -it（سَلَطَة ➞ سَلَطِت）也要一起记。

用 مِش 构成否定

مِش（也读 mush）意为「不」，能把许多简单词组和句子变成否定，直接放在要否定的成分前面即可：名词、形容词、国籍词、指示词句都能用。教材设计的练习是「被人认错了」——对方说的信息全不对，用 لَأْ، أَنَا مِش … 逐条纠正；女性说话时别忘了把形容词也改成阴性。
هِنَا ➞ مِش هِنَا
在这儿 → 不在这儿
原书罗马音：hína ➞ mish hína
صَاحِي ➞ مِش صَاحِي
醒着 → 没醒
原书罗马音：SáaHi ➞ mish SáaHi
أَنَا دُكْتُور. ➞ أَنَا مِش دُكْتُور.
我是医生 → 我不是医生
原书罗马音：ána duktúur. ➞ ána mish duktúur.
هُوَّ مَصْرِي. ➞ هُوَّ مِش مَصْرِي.
他是埃及人 → 他不是埃及人
原书罗马音：húwwa máSri. ➞ húwwa mish máSri.
دِي أُمِّي. ➞ دِي مِش أُمِّي.
那是我妈妈 → 那不是我妈妈
原书罗马音：di úmmi. ➞ di mish úmmi.
مِش 否定的正是「没有系动词」的名词句，位置固定在被否定成分之前。它和动词否定 ma … -sh 的分工，后面单元还会细讲，先把本单元这些名词句练熟。

职业的阴性 -a，与外部复数 -íin / -áat

多数职业名词加 -a 变阴性，重音常随之后移：مُدَرِّس ➞ مُدَرِّسَة、دُكْتُور ➞ دُكْتُورَة。复数先学「外部复数」两套词尾：-íin 只用于指人的名词（职业、国籍等），-áat 多用于较长或外来词的阴性、阳性名词，加 -áat 前先去掉词尾 -a。单数若以长元音收尾，加复数词尾时要短化；以元音收尾的词，则要插入 yy 或 y 才顺口。教材说明：改元音的「内部复数」留到后面单元，本单元只练外部复数。
مُدَرِّس ➞ مُدَرِّسَة
教师（男）→ 教师（女）
原书罗马音：mudárris ➞ mudarrísa
مُدَرِّس ➞ مُدَرِّسِين / مُمَثِّل ➞ مُمَثِّلِين
教师 → 教师们／演员 → 演员们
原书罗马音：mudárris ➞ mudarrisíin / mumássil ➞ mumassilíin
تَرَابَيْزَة ➞ تَرَابَيْزَات / تِلِفُون ➞ تِلِفُونَات
桌子 → 桌子们／电话 → 电话们
原书罗马音：tarabáyza ➞ tarabayzáat / tilifóhn ➞ tilifohnáat
مَصْرِي ➞ مَصْرِيِّين
埃及人 → 埃及人们（插入 yy）
原书罗马音：máSri ➞ maSriyyíin
هُوَّ مُهَنْدِس. ➞ هُمَّا مُهَنْدِسِين.
他是工程师 → 他们是工程师
原书罗马音：húwwa muhándis. ➞ húmma muhandisíin.
口诀：指人用 -íin，长词外来词用 -áat；-a 先去掉再加 -áat。埃及口语里 -íin 通常男女通用，不必另造一套阴性复数。

06 文化点滴

埃及人的待客之道，与街头的鲜榨果汁摊

饮食在阿拉伯人的待客礼数里分量极重。到人家做客，主人几乎总会端上一杯热饮或冷饮：装在玻璃杯里的甜红茶（shay）、咖啡（áhwa），或是一杯冷饮、洛神花茶（kárkaday）；还可能配上点心——淋了糖浆的果仁千层酥（教材罗马音作 ba’láawa）、炸面团球（lú’mit il-’áaDi）、粗粒小麦粉蛋糕（basbúusa），或随处可见的奶油蛋糕。若正赶上饭点，多半会被留下一起用餐。教材另有一处文化点讲到埃及各地的传统鲜榨果汁摊：用当地果蔬现榨，通常当场喝上一杯，也可以装瓶带走，价格很实惠。

给中国学习者：主人殷勤劝饮时，直接说「不」略显生硬，最好像课文里的哈桑那样补一句理由（لِسَّة شَارِب「刚喝过」），或先谢过再婉拒；接受时说 أَيْوَا، مِنْ فَضْلَك 最得体。点饮料不妨试试 عَصِير لَيْمُون（柠檬汁），正是街头果汁摊的招牌款。

07 本单元所学字母

ح
哈乌（送气 h）　حَاء
读带明显气流的 h，想象对着眼镜哈气准备擦拭时呼出的那口气
与 ج、خ 共用一个骨架，ح 不带点；字母下弯的尾巴只在词尾才保留。教材录音另安排了含 ح / خ 的跟读词：حَسَن、إِحْنَا、فَرَح、خَال、خَمْسَة、سَبَانِخ
ج
吉姆　جِيم
埃及口语读 g，接近汉语「哥」的声母；标准语则读成柔和的 j 音
一点在下方；本套教材一律按埃及音 g 来读，不必发成 j。它和 ح、خ 靠点的有无与位置区分
خ
赫乌（喉音）　خَاء
读喉部摩擦音 kh，比汉语「喝」更靠后，像轻轻哈气时摩擦出来的音
一点在上方；三字母共用一个骨架，只有写到词尾才显出各不相同的形状

✓ 本单元小结

本单元我们学会了向客人敬茶敬食（تِشْرَب / تَاكُل / تِحِبّ）、礼貌接受（أَيْوَا، مِنْ فَضْلَك）或婉拒并附上理由（لَأْ، شُكْرًا. لِسَّة شَارِب.），也记下了一整张埃及饮品与菜肴清单，从 شَاي、أَهْوَة 到 كَبَاب、طَعْمِيَّة。语法上掌握了用 عَنْد ＋接尾代词表示「有」、正偏组合 إِضَافَة 的语序与冠词位置、مِش 构成的否定句，以及职业名词的阴性 -a 与外部复数 -íin / -áat；还学会用 بِتِشْتَغَل إِيهْ؟ 谈论职业。文化上体会了埃及人殷勤待客与街头鲜榨果汁摊的风俗，书写上则辨清了 ح、ج、خ 三个同骨架字母。
